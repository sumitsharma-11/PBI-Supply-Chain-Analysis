# PBI-Supply-Chain-Analysis

Supply Chain Analysis Dashboard 🚚📦

Project Overview
This Power BI project provides a comprehensive analysis of supply chain operations, focusing on key performance indicators (KPIs) such as logistics efficiency, order fulfillment, and cost management. The dashboard is designed to help stakeholders identify bottlenecks, optimize inventory levels, and improve overall supply chain transparency.

Key Features & Insights 
Order Tracking & Fulfillment: Real-time monitoring of order statuses and delivery timelines.
Logistics Efficiency: Analysis of shipping modes, carrier performance, and transit times.
Cost Analysis: Deep dive into procurement costs, shipping expenses, and overall operational expenditure.
Inventory Management: Visualizations of stock levels to prevent overstocking or stockouts.
Geospatial Analysis: Map-based views of distribution centers and customer locations.

Data Source
The project utilizes a structured dataset containing information on:
Order details (Dates, Quantities, Status).
Product categories and pricing.
Customer demographics and shipping locations.
Supplier and carrier performance metrics.

Visualizations Included
Executive Summary: High-level KPIs for total revenue, total orders, and average shipping time.
Product Performance: Analysis of top-performing products and categories.
Regional Analysis: Interactive map showing sales and logistics performance by region.
Trend Analysis: Time-series charts showing seasonal trends in order volume and costs.

Tools Used
Power BI Desktop: For data modeling, DAX calculations, and report visualization.
Power Query: For data cleaning and transformation (ETL).
DAX (Data Analysis Expressions): Used for creating complex measures and calculated columns.
